# network_location_client

Wi-Fi-позиционирование: сканирует видимые точки доступа (`wifi_scan`) и
восстанавливает позицию через MLS-совместимый сервис геолокации
([BeaconDB](https://beacondb.net) — бесплатный, без API-ключа).

Используется картой друзей как fallback в помещениях, где GNSS не ловит,
а сетевые геопровайдеры в регионе деградировали.

- `scanAccessPoints()` — список видимых точек (только Android; на других
  платформах возвращает пустой список). Рандомизированные/локально-
  администрируемые MAC и сети с суффиксом `_nomap` отфильтровываются.
- `geolocate(aps)` — позиция по списку точек или `null`, если сервис их
  не знает (требуется минимум две точки — как в MLS).
